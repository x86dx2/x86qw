# x86QW 0.5.0

A functional release of the new menus, declarative Frogbot profiles and
contextual controls for the five current games.

## Interface

- organizes the menus by task, numbers every option and keeps the descriptions
  aligned on the same line;
- navigates with the arrows and Enter, goes back to the parent menu with the
  left arrow and leaves the whole flow with Esc;
- fixes reading arrow sequences on interactive terminals;
- keeps automatic confirmation with `--yes` and the numbered fallback.

## KTX and Frogbots

- gathers catalog, configuration, runtime, sources and policy into separate
  contexts inside the KTX component;
- offers the `KTX Default` names, random `x86QW` names and an editable personal
  list;
- applies random names and skills without replacing the skins, colors or teams
  KTX controls;
- fills the roster according to each usermode, including three teams in the
  `2on2on2`, `3on3on3` and `4on4on4` modes;
- loads the 24 declared modes and adds the chosen bots after the local server
  entry;
- prints a contextual key plan and binds F12 to quit directly in the five
  current games.

## Bootstrap and compatibility

- the PowerShell bootstrap returns the installer's code without closing the
  session used by `irm ... | iex`;
- keeps the public commands, profiles, stable/nightly, PAKs, maps, runtimes
  and personal settings;
- publishes new immutable revisions of KTX, Final Arena, Pro-X, Team Fortress
  and Total Destruction 2 without changing the earlier packages.

## Validation

- 326 maintenance tests and four site tests;
- the Ubuntu, macOS and Windows matrix with Python 3.10 and 3.13;
- a real smoke in a KTX 4on4 window with seven Frogbots on macOS;
- F12 exercised in KTX, Final Arena, Pro-X, Team Fortress and TD2;
- Git LFS, catalog, zipapp, packages and site validated before publishing.
