## Limite do registro

Este foi um rehearsal `owner-only`, sem publicação, sem alteração de GitHub Release, GitLab, TUF ou site, e sem alegação de evidência M3. Portanto, ele fecha o defeito de empacotamento, mas não autoriza `1.0.0` nem substitui os gates protegidos da promoção final.
