# x86QW 1.0.0 — rascunho

> Estado: **não publicada, não current e não aprovada**.

Este arquivo é somente um rascunho de notas para a futura linha 1.0.0. A
versão pública continua sendo `0.7.3`; nenhum bootstrap, catálogo, bundle, tag
ou mirror aponta para este documento.

## Escopo previsto

- contratos SemVer, estado, recibos e saída JSON congelados;
- migração unilateral com preservação de ownership e dados pessoais;
- downloader e fronteira de arquivos únicos, com limites e promoção atômica;
- catálogo e metadata autenticados por trust root rotacionável;
- candidato construído uma vez e validado sem rebuild;
- validação completa no macOS sem smokes nativos ou runners externos;
- documentação factual e governança de release revisadas.

## Bloqueadores antes de qualquer publicação

- fixtures reais de toda versão histórica suportada;
- chave de produção, revisão criptográfica independente e cerimônia de trust;
- revisão humana do candidato e dos controles de trust antes de uma publicação
  remota opcional;
- validação pós-publicação em instalações limpas.

Nenhum item acima pode ser substituído por fixture sintético, variável de
ambiente ou afirmação de plataforma não validada. A promoção local ocorre
diretamente no Mac por candidato imutável; uma publicação remota é uma ação
separada e exige autorização explícita, trust e P0/P1 aplicáveis. Linux-X64, Windows-X64, macOS-ARM64 e
macOS-X64 continuam preservados como compatibilidade/catalogo, mas não entram
como bloqueadores deste fluxo Mac.
