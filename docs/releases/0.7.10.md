# x86QW 0.7.10

Hotfix da criação automática do filtro Git seletivo da instalação.

## Correção

- cria `quake-world/.gitignore` automaticamente ao concluir uma instalação;
- restaura o filtro quando `x86qw update` encontra o conteúdo já atualizado;
- atualiza o filtro após aplicar updates de componentes;
- ignora somente os caminhos exatos registrados nos inventories, mantendo
  arquivos novos visíveis ao Git;
- mantém `x86qw changes` como comparação por hash capaz de mostrar arquivos
  padrão modificados ou removidos, que o `.gitignore` sozinho não detecta;
- preserva `x86qw changes --sync-gitignore` como regeneração manual.

A release 0.7.9 permanece histórica e imutável. O bootstrap público passa a
apontar para o bundle 0.7.10 e para a versão seguinte da metadata TUF.

## Validação

- regressão RED para instalação sem `.gitignore`;
- regressões para update sem novidades e update com plano aplicado;
- suíte completa do instalador e comparação de mudanças;
- gate completo de manutenção, site e contratos portáveis.
