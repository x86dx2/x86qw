# x86QW 0.7.10

A hotfix of creating the installation's selective Git filter automatically.

## Fix

- creates `quake-world/.gitignore` automatically when an install finishes;
- restores the filter when `x86qw update` finds the content already up to
  date;
- updates the filter after applying component updates;
- ignores only the exact paths recorded in the inventories, keeping new files
  visible to Git;
- keeps `x86qw changes` as a hash comparison that can show modified or removed
  default files, which `.gitignore` alone cannot detect;
- keeps `x86qw changes --sync-gitignore` as the manual regeneration.

Release 0.7.9 stays historical and immutable. The public bootstrap now points
at the 0.7.10 bundle and at the next version of the TUF metadata.

## Validation

- a RED regression for an install without `.gitignore`;
- regression tests for an update with nothing new and an update with an
  applied plan;
- the full installer and change comparison suite;
- the full maintenance, site and portable contracts gate.
