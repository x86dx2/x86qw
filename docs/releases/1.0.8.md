# x86QW 1.0.8

The source and the current installer move to `1.0.8`. `1.0.7` stays
historical and immutable on the mirrors.

## What goes in

- replaces the repeated preparation, cache, install and verification lines
  with a compact cycle inspired by Homebrew;
- groups the full plan into ezQuake and x86QW components before the
  confirmation;
- aggregates packages already in the cache per phase, with count and size;
- keeps only the current package as transient activity on a TTY terminal;
- records one persistent line per phase and a single final verification;
- keeps the detailed listing of versions and receipts with `--verbose`;
- applies the same model to `install`, `update` and `upgrade`.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- 1,976 full maintenance tests, with 39 expected skips;
- 16 site tests;
- portable contracts on macOS and Ubuntu with Python 3.10 and 3.13;
- CodeQL with no new alerts;
- a real isolated install of the 21 components and verification of 737 files;
- deterministic validation of the bundle, catalog, mirrors and TUF.
