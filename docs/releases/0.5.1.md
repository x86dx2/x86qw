# x86QW 0.5.1

Correção do bootstrap público para instalações Windows sem um Python funcional.

## PowerShell

- testa uma versão real do Python antes de baixar o instalador;
- aceita `py -3`, `python3` e `python`, nessa ordem;
- rejeita o alias vazio da Microsoft Store em vez de terminar posteriormente
  com o código `9009`;
- exige Python 3.10 ou mais recente e apresenta um comando `winget` acionável
  quando o requisito não está instalado;
- mantém o bootstrap legível no Windows PowerShell antigo e restaura a
  codificação da sessão ao terminar;
- continua preservando a janela atual e o código de saída do instalador.

## Compatibilidade

- não altera gameplay, pacotes dos cinco jogos, runtimes, PAKs, perfis ou
  configurações pessoais;
- preserva integralmente o instalador imutável `0.5.0`.

## Validação

- cobre ausência de Python, falso alias da Microsoft Store, `py -3`, código de
  saída e permanência da sessão PowerShell;
- mantém a regressão multiplataforma e os contratos do site.
