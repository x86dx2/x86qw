# x86QW 0.5.1

A fix to the public bootstrap for Windows installations without a working
Python.

## PowerShell

- tests a real Python version before downloading the installer;
- accepts `py -3`, `python3` and `python`, in that order;
- rejects the empty Microsoft Store alias instead of failing later with code
  `9009`;
- requires Python 3.10 or newer and shows an actionable `winget` command when
  the requirement is not installed;
- keeps the bootstrap readable on old Windows PowerShell and restores the
  session's encoding when it ends;
- still keeps the current window and the installer's exit code.

## Compatibility

- does not change gameplay, the packages of the five games, runtimes, PAKs,
  profiles or personal settings;
- keeps the immutable `0.5.0` installer entirely intact.

## Validation

- covers a missing Python, the fake Microsoft Store alias, `py -3`, the exit
  code and the PowerShell session staying open;
- keeps the cross-platform regression and the site contracts.
