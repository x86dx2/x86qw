# x86QW 1.0.6

The source and the current installer move to `1.0.6`. `1.0.5` stays
historical on the mirrors and was not promoted as current on the site/TUF.

## What goes in

- keeps the definitive fix of the canonical `qw.x86.com.br` domain, without
  restoring the old domain or using it as a fallback;
- keeps the compact banner with the name, pitch, site and version before the
  download;
- keeps the hybrid terminal flow and the short PowerShell message, without
  dumping the script on failures;
- sanitizes the paths of the `doctor` report on Windows too;
- prints the path of the local panel portably;
- escapes the visual separators of the `x86qw.cmd` help text, so `cmd.exe` does
  not read them as pipelines and return code 255.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows stays preview, now with its automated contract green again.

## Validation

- regression tests of the bootstrap/banner and the rejection of the old domain;
- regression tests of sanitization and the panel path on Windows;
- real runs of the `.cmd` launcher on Windows with Python 3.10 and 3.13;
- deterministic validation of the bundle, catalog, mirrors and TUF.
