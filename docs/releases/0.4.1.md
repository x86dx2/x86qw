# x86QW 0.4.1

A corrective release of the x86QW CLI's interactive navigation.

## Keyboard

- reads the complete CSI and SS3 sequences the arrow keys produce;
- keeps keys already queued, including an Enter right after an arrow;
- ignores unknown terminal sequences instead of turning them into a cancel;
- keeps navigation with the arrows, `j`/`k`, Enter, Esc and the numbered
  fallback.

## Presentation

- colors the whole line of the selected option on capable terminals;
- aligns items and descriptions with `|` as the divider;
- shows the explanation of the selected option on its own line;
- keeps the text marker `›` when colors are off;
- spells out the consequence of the `Sim` and `Não` answers in confirmations.

## Compatibility

Every public command and flag stays available. Games, gameplay, profiles,
runtimes, PAKs and the installed layout did not change.

## Validation

- 289 maintenance tests and four site tests;
- the Ubuntu, macOS and Windows matrix with Python 3.10 and 3.13;
- a PTY regression for arrows, a queued Enter, colors, alignment and
  cancelation;
- Git LFS, catalog, zipapp and a deterministic bundle;
- a Worker dry run and explicit publishing after approval.
