# x86QW 0.7.4

A corrective release of x86QW's platform truth and validation matrix.

> Status: a candidate prepared in a separate release PR. The tag and the public
> release will be created only after the merge and the authorized remote
> publishing step.

## Platform truth

- separates having an artifact, declared support and executed validation;
- keeps the universal macOS client as conditional support;
- classifies Linux, Windows, macOS services and variants not yet put through a
  native smoke as preview when that is the evidence available;
- records `portable-contract` for the validation of catalog, contracts, paths
  and CLI, without presenting it as a native runtime smoke;
- declares no M3 evidence, Developer ID signature, notarization or production
  operational trust.

## Entry evidence

- the platform fix was merged by PR #66 in `db5f7088`;
- the seven protected contexts passed on the final head of PR A;
- this PR adds the 0.7.4 identity, the derived artifacts and the regression
  test of the corrective release.

## Integrity

The 0.7.3 bundle stays historical and immutable. The 0.7.4 package will count
as public only after the tag, the asset, the mirrors, the catalog and the
bootstraps are verified after publishing.
