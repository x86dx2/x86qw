> Estado: candidata preparada em uma PR de release separada. A tag e a

> publicação autorizada.

## Verdade de plataforma

- separa presença de artefato, suporte declarado e validação executada;
- conserva o cliente macOS universal como suporte condicional;
- classifica Linux, Windows, serviços macOS e variantes ainda não submetidas a
  smoke nativo como preview quando essa é a evidência disponível;
- registra `portable-contract` para a validação de catálogo, contratos,
  caminhos e CLI, sem apresentar isso como smoke nativo de runtime;
- não declara evidência M3, assinatura Developer ID, notarização ou confiança
  operacional de produção.
