# x86QW 0.4.2

A corrective release of the local KTX modes and of starting Frogbots.

## KTX modes

- keeps compound alias bodies intact until the local server entry;
- installs only the entry event that matches the chosen usermode;
- opens the 24 declared modes, including the seven official variants;
- finishes the Practice profile on the first entry, without waiting for a
  reload that never comes;
- avoids an ownership conflict over the Frogbot cvars in ThunderWalker ToT.

## Frogbots

- adds the chosen bot automatically in the 22 compatible modes;
- applies count, skill, team, weapon and health only after KTX confirms the
  local connection;
- fills each mode's fixed roster automatically and spreads the bots over the
  declared teams: `3on3` uses two teams of three and `2on2on2` uses three teams
  of two;
- keeps CTF and Race without bots, as the KTX 1.47 contract says.
- draws each bot's skill independently when asked;
- offers the KTX Default names, random One Piece x86QW names and a personal
  list;
- keeps KTX's default relational skins and colors during Frogbot sessions too,
  with no visual override by the launcher.

## Interface and controls

- numbers every menu option, aligns the descriptions in a gray column and keeps
  the selected item's detail on the same line;
- standardizes the legend as `↑↓ navegar`, `→/Enter selecionar`, `← voltar`
  and `Esc Sair`;
- separates going back to the parent with the left arrow from leaving the flow
  with `Esc`;
- prints, per game and per mode, only the actions actually bound to keys;
- organizes the KTX layer the project maintains into `catalog/`, `config/`,
  `runtime/`, `source/` and `policy/`, without changing the installed tree.

## Compatibility

Commands, profiles, runtimes, maps, PAKs and personal settings stay
compatible. The KTX QVM extension stays minimal, reproducible and inert
without the x86QW cvars.

## Validation

- 324 maintenance tests and four site tests;
- the Ubuntu, macOS and Windows matrix with Python 3.10 and 3.13;
- the PowerShell bootstrap keeps the session that runs `irm ... | iex` and
  keeps the code returned by the Python installer visible;
- a real smoke of the 24 modes in ezQuake 3.6.9 in a `1280x720` window on
  macOS;
- Frogbot confirmed in the 22 compatible modes;
- personal settings kept, and no leftover process or log;
- Git LFS, catalog, zipapp and deterministic bundles.
