# x86QW 1.0.13

The source and the current installer move to `1.0.13`. `1.0.12` stays
historical and immutable on the mirrors.

## What goes in

- fixes the custom flow and keeps the plan true to the chosen components;
- presents the plan in a compact table with package, version, size and
  target;
- applies x86QW's visual identity to the bootstrap and the installer menus;
- installs only the platform's native launcher;
- publishes the `x86qw` command on the user's PATH on macOS/Linux;
- creates shortcuts in the Start Menu and on the Desktop on Windows, with the
  official icon.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- regression tests cover the custom selection, the plan, the launchers and the
  native integrations;
- bootstrap compatibility kept for Windows PowerShell 5.1;
- the full maintenance suite and the portable contracts;
- the public promotion verified after publishing.
