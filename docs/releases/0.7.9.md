# x86QW 0.7.9

A fix to the comparison of local changes after a clean install.

## Fix

- records the personal settings files the installer creates in a
  transactional baseline, separate from the managed components;
- makes `x86qw changes` take that baseline into account, so the default files
  just installed are no longer flagged as new;
- adds `x86qw changes --sync-gitignore` to ignore only the installation's exact
  files and keep new files visible to Git;
- adopts legacy settings only when their bytes still match the template,
  keeping existing personal changes;
- keeps the comparison portable and deterministic on Linux, macOS and Windows.

Release 0.7.8 stays historical and immutable. The public bootstrap now points
at the 0.7.9 bundle and at the next version of the TUF metadata.

## Validation

- regression tests for a clean install and a new, modified and removed file;
- regression tests for rollback and the safe adoption of legacy settings;
- the full maintenance and site gate;
- portable GitHub Actions contracts with Python 3.10 and 3.13 on macOS, Linux
  and Windows.
