# x86QW 0.7.9

Correção da comparação de mudanças locais após uma instalação limpa.

## Correção

- registra os arquivos de configuração pessoal criados pelo instalador em um
  baseline transacional separado dos componentes gerenciados;
- faz `x86qw changes` considerar esse baseline, evitando marcar como novos os
  arquivos padrão acabados de instalar;
- adiciona `x86qw changes --sync-gitignore` para ignorar somente os arquivos
  exatos da instalação e manter arquivos novos visíveis ao Git;
- adota configurações legadas apenas quando os bytes ainda são idênticos ao
  template, preservando alterações pessoais existentes;
- mantém a comparação portátil e determinística em Linux, macOS e Windows.

A release 0.7.8 permanece histórica e imutável. O bootstrap público passa a
apontar para o bundle 0.7.9 e para a versão seguinte da metadata TUF.

## Validação

- regressões de instalação limpa, arquivo novo, alterado e removido;
- regressões de rollback e adoção segura de configurações legadas;
- gate completo de manutenção e site;
- contratos portáveis do GitHub Actions com Python 3.10 e 3.13 em macOS, Linux
  e Windows.
