# x86QW 1.0.14

The source and the current installer move to `1.0.14`. `1.0.13` stays
historical and immutable on the mirrors.

## What goes in

- fixes publishing the CLI installed by the official bundle on macOS/Linux;
- reads the embedded icon only after validating the ZIP file's plan;
- keeps the `x86qw` command on the user's PATH and the platform's native
  launcher;
- keeps the custom flow, the compact plan and the visual identity introduced in
  `1.0.13`.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- a regression test runs the CLI install from the real packaged zipapp;
- a public smoke installs the client and the components into a throwaway
  target;
- the full maintenance suite and the portable contracts;
- the public promotion verified after publishing.
