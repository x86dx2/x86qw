# x86QW 0.7.8

A hotfix of starting Frogbots in local KTX matches.

## Fix

- keeps the Frogbot management aliases at the top level of the ephemeral
  configuration;
- makes the KTX entry event call a single root alias, so ezQuake no longer
  drops the post-map sequence when the configuration is long;
- fixes the `3on3on3` command with eight bots, skill 20, x86QW names and the
  `aerowalk` map;
- adds an automated regression test for the exact command reported and keeps
  the ToT, Practice, Race and CTF flows.

Release 0.7.7 stays historical and immutable. The public bootstrap now points
at the 0.7.8 bundle and at the next version of the TUF metadata.

## Validation

- a RED regression reproducing the invalid chain of 23 aliases;
- six targeted KTX tests;
- the full suite of modern components;
- the full maintenance and site gate;
- portable GitHub Actions contracts on macOS, Linux and Windows.
