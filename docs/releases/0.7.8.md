# x86QW 0.7.8

Hotfix da inicialização de Frogbots nas partidas KTX locais.

## Correção

- mantém os aliases de gerenciamento de Frogbots no nível superior da
  configuração efêmera;
- faz o evento de entrada do KTX chamar um único alias raiz, evitando que o
  ezQuake descarte a sequência pós-mapa quando a configuração é longa;
- corrige o comando `3on3on3` com oito bots, habilidade 20, nomes x86QW e mapa
  `aerowalk`;
- adiciona regressão automatizada para o comando exato relatado e preserva os
  fluxos ToT, Practice, Race e CTF.

A release 0.7.7 permanece histórica e imutável. O bootstrap público passa a
apontar para o bundle 0.7.8 e para a versão seguinte da metadata TUF.

## Validação

- regressão RED reproduzindo a cadeia inválida de 23 aliases;
- seis testes KTX direcionados;
- suíte completa de componentes modernos;
- gate completo de manutenção e site;
- contratos portáveis do GitHub Actions em macOS, Linux e Windows.
