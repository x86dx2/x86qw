# x86QW 0.7.7

Hotfix do perfil Completo para pacotes grandes autenticados.

## Correção

- permite o hashing de arquivos ZIP de componentes com até 512 MiB, o mesmo
  limite já aplicado ao download e ao arquivo-fonte do extrator;
- mantém em 128 MiB o limite individual de cada arquivo extraído;
- corrige a instalação do QRP alta resolução, cujo pacote tem aproximadamente
  385,4 MiB;
- adiciona regressão que reproduz a falha `EFBIG` observada no perfil Completo.

A release 0.7.6 permanece histórica e imutável. O bootstrap público passa a
apontar para o bundle 0.7.7 e para a versão seguinte da metadata TUF.

## Validação

- suíte completa de manutenção e site;
- instalação dos 21 componentes pelo perfil Completo;
- atualização e verificação pela CLI instalada;
- hashes conferidos nos mirrors GitHub e GitLab.
