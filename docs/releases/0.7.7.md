# x86QW 0.7.7

A hotfix of the Complete profile for large authenticated packages.

## Fix

- allows hashing component ZIP files of up to 512 MiB, the same limit already
  applied to the download and to the extractor's source file;
- keeps the per-file limit of each extracted file at 128 MiB;
- fixes the install of QRP high resolution, whose package is about 385.4 MiB;
- adds a regression test that reproduces the `EFBIG` failure seen in the
  Complete profile.

Release 0.7.6 stays historical and immutable. The public bootstrap now points
at the 0.7.7 bundle and at the next version of the TUF metadata.

## Validation

- the full maintenance and site suite;
- an install of the 21 components through the Complete profile;
- update and verification through the installed CLI;
- hashes checked on the GitHub and GitLab mirrors.
