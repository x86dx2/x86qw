# x86QW 1.0.7

The source and the current installer move to `1.0.7`. `1.0.6` stays
historical and immutable on the mirrors.

## What goes in

- shows the full install plan before any change;
- requires an explicit confirmation before installing and explains the
  `install --non-interactive` contract when there is no interactive terminal;
- names each package and phase during downloads, checks and install;
- shows the size received/total and keeps visual progress on a TTY terminal;
- reports download, extraction, verification and the installer's start
  separately in the Unix and PowerShell bootstraps;
- limits and sanitizes public labels before printing them on the terminal.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- the full maintenance and site suite on macOS;
- portable contracts on macOS and Ubuntu with Python 3.10 and 3.13;
- the Windows contract with Python 3.10 and 3.13;
- CodeQL and specific regression tests of the plan, confirmation and progress;
- deterministic validation of the bundle, catalog, mirrors and TUF.
