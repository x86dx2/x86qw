# x86QW 0.3.0

A clean-bootstrap release that reorganizes the installed layout.

## Layout

- replaces `.install/` with `.x86qw/` as the product's own control plane;
- drops the installed `_x86qw/` store;
- installs MVDSV at the operational root, QTV in `qtv/`, QWFWD in `qwfwd/` and
  the licenses in `docs/licenses/`;
- installs only the executable of the selected platform;
- keeps `BUILD.json`, sources, patches and other variants in the maintenance
  layer only.

## Compatibility

This line uses a clean bootstrap and does not migrate the 0.2.x layout. An
earlier installation can be kept in another folder for reference only. Games,
gameplay, profiles, stable/nightly and public commands are unchanged.

## Validation

- a deterministic package and zipapp;
- a full bootstrap into an empty target;
- an assertion that `_x86qw/`, `platforms/` and `BUILD.json` are absent from
  the target;
- the Ubuntu, macOS and Windows matrix;
- explicit publishing after approval and verification of the public bootstrap.
