# x86QW 0.7.6

A hotfix of the public installer's TUF refresh.

## Fix

- keeps the HTTP 404 status received when asking for the next version of
  `root.json`, so the TUF client can finish the root rotation normally when no
  later version exists;
- keeps the download limits, the authenticated catalog and the fail-closed
  behavior for any other trust failure;
- adds a regression test that reproduces the error conversion done by the
  installer's downloader.

Release 0.7.5 stays historical and immutable. The public bootstrap now points
at the 0.7.6 bundle and at the new monotonic version of the TUF metadata.

## Validation

- a real TUF refresh against the public domain;
- a new, isolated install through the public bootstrap;
- update and verification through the installed CLI;
- hashes checked on the GitHub and GitLab mirrors.
