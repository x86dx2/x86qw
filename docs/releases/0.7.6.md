# x86QW 0.7.6

Hotfix do refresh TUF do instalador público.

## Correção

- preserva o status HTTP 404 recebido ao consultar a próxima versão de
  `root.json`, permitindo que o cliente TUF encerre normalmente a rotação de
  root quando não existe uma versão posterior;
- mantém os limites de download, o catálogo autenticado e o comportamento
  fail-closed para qualquer outra falha de trust;
- adiciona regressão que reproduz a conversão de erro feita pelo downloader do
  instalador.

A release 0.7.5 permanece histórica e imutável. O bootstrap público passa a
apontar para o bundle 0.7.6 e para a nova versão monotônica da metadata TUF.

## Validação

- refresh TUF real usando o domínio público;
- instalação nova isolada pelo bootstrap público;
- atualização e verificação pela CLI instalada;
- hashes conferidos nos mirrors GitHub e GitLab.
