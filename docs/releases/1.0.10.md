# x86QW 1.0.10

The source and the current installer move to `1.0.10`. `1.0.9` stays
historical and immutable on the mirrors.

## What goes in

- keeps each `[n/total] Processando pacote` status on a persistent line;
- drops the carriage return and the ANSI sequence that erased the previous
  status;
- keeps the progress lines both on a TTY and in redirected/PowerShell output;
- keeps a single final summary for the components phase.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- a TDD regression test seen red before the implementation;
- 1,985 full maintenance tests, with 39 expected skips;
- portable contracts on macOS and Ubuntu with Python 3.10 and 3.13;
- CodeQL with no new alerts;
- deterministic validation of the bundle, catalog, mirrors and TUF.
