# x86QW 1.0.2

Fonte e instalador current passam a `1.0.2`. A `1.0.1` e a `0.7.13` permanecem
no catálogo como históricas, não como current.

## O que entra

- `migrate --dry-run` autentica a linha `1.0.x` (incluindo `1.0.1`/`1.0.2`);
  uma instalação current deixa de ser tratada como história sem família;
- `cleanup` finaliza o cache Darwin quando `root.json` do TUF é symlink.

## O que não muda

- audiência `owner-only`; `external-public` continua `NO-GO`;
- pacotes e tags `0.7.13`, `1.0.0` e `1.0.1` permanecem imutáveis;
- fixtures de migração `0.7.0–0.7.13` ficam como história, não como current.

## Validação

- testes de estado/`migrate` para `1.0.1` e de `cleanup` com symlink TUF;
- harness nativo M3 25/25 no digest exato deste zip.
