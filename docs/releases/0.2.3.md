# x86QW 0.2.3

A corrective release of session journal compatibility in the `0.2.x` line.

## Fix

- accepts clean journals written before the `controller`, `type` and
  `sensitive` fields existed;
- normalizes the legacy format only in memory, without rewriting a clean
  journal during `update`, `upgrade` or any other operation;
- treats unclassified legacy temporaries as sensitive when an actual recovery
  is needed;
- removes the hashes of legacy temporaries classified as sensitive before
  persisting the result of the recovery.

## Compatibility

The fix keeps journals, personal settings, commands, profiles, stable/nightly,
games and gameplay. The `0.2.2` and earlier bundles stay immutable.

## Validation

- reproduction with a real journal created by the previous version;
- a regression test for a clean legacy journal, without querying the recorded
  PID;
- safe recovery of a potentially sensitive legacy temporary;
- full validation and the Ubuntu, macOS and Windows matrix.
