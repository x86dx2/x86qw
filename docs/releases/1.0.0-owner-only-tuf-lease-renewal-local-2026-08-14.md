# Renovação local da lease TUF — x86QW 1.0.0 owner-only

Em 14 de agosto de 2026, o build final `31836825691` parou antes de construir o candidato porque a metadata `timestamp.json` versionada expirou às `2026-08-14T18:54:56Z`.

Foi executada uma renovação estritamente `timestamp-only` em diretório temporário, usando a chave timestamp local autorizada. A operação mudou somente `metadata/timestamp.json`, de versão `14` para `15`, com validade até `2026-08-15T20:16:11Z`. A assinatura e o vínculo com o catálogo foram verificados pelo próprio utilitário de renovação; `maintenance/manage.py verify --no-tests` passou depois da atualização.

Este registro não afirma publicação. A renovação pública do RC e a metadata TUF final continuam sendo operações protegidas e serão encadeadas nos próximos gates.

Os hashes, a chave pública usada, o catálogo e as limitações estão no registro JSON associado.
