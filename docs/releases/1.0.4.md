# x86QW 1.0.4

Fonte e instalador current passam a `1.0.4`. A `1.0.3`, a `1.0.2`, a `1.0.1`,
a `1.0.0` e a `0.7.13` permanecem no catálogo como históricas, não como current.

## O que entra

- bootstrap público compatível com Windows PowerShell 5.1, sem transportar
  programas Python multilinha por `python -c`;
- cache TUF no Windows usa um arquivo regular autenticado para `root.json`,
  dispensando privilégio de criação de link simbólico (WinError 1314).

## O que não muda

- audiência `owner-only`; `external-public` continua `NO-GO`;
- pacotes e tags anteriores permanecem imutáveis;
- a validação de SHA-256, tamanho, ZIP e metadata TUF continua fail-closed.

## Estado operacional verificado

- `MAIN=GREEN` no Validate `33124929611`;
- `TUF=HEALTHY`: root v1, timestamp v28 e snapshot/targets v27;
- a projeção owner-only foi reparada e verificada no run `33125534974`;
- a fonte current é `1.0.4`; a release publicada continua sendo o candidato
  `1.0.0` owner-only, válido para o mantenedor no Apple M3.

O estado completo, incluindo hashes, limites de audiência e gates estacionados,
está em [`RELEASE-TRUTH-CURRENT.md`](../post-1.0/RELEASE-TRUTH-CURRENT.md).

## Validação

- regressão da falha WinError 1314 e autenticação do catálogo;
- harness nativo do Windows PowerShell 5.1 para materialização do extrator;
- Validate portátil no corte da fonte.
