# x86QW 1.0.11

The source and the current installer move to `1.0.11`. `1.0.10` stays
historical and immutable on the mirrors.

## What goes in

- fixes the release that reused TUF `timestamp` v32 with different signed
  bytes;
- binds the signed handoff to the exact timestamp of the release projection;
- rejects equivocation and rollback before any deploy;
- requires a monotonic renewal of exactly `N+1`;
- publishes GitHub and GitLab in the same protected workflow, before the
  byte-for-byte comparison.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- TDD regression tests cover equivocation, rollback and incomplete publishing
  to the mirrors;
- the full maintenance suite and the portable contracts;
- deterministic validation of the bundle, catalog, mirrors and TUF;
- the public promotion verified after publishing.
