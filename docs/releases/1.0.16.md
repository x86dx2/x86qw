# x86QW 1.0.16

The source and the current installer move to `1.0.16`. `1.0.15` stays
historical and immutable on the mirrors.

## What goes in

- fixes the `x86qw` command installed on the PATH on macOS/Linux by resolving
  the symbolic link before locating the installation's private CLI;
- restores two missing cells in the logo the PowerShell bootstrap shows;
- keeps the logo's full geometry identical across PowerShell, Bash and Python;
- adds regression tests that run the command through the real link and check
  every line of the logo in PowerShell.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier versions stay historical and immutable;
- SHA-256, size, ZIP and TUF metadata stay fail-closed;
- Windows and Linux stay preview; the operational gate stays Apple M3.

## Validation

- a real run of the launcher through `~/.local/bin/x86qw`;
- real PowerShell rendering in a PTY, checking the whole geometry;
- the full maintenance suite and the portable contracts;
- the public promotion verified after publishing.
