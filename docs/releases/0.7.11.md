# x86QW 0.7.11

A hotfix of the installed permanent CLI's dispatcher.

## Fix

- accepts `x86qw changes` in the Unix and Windows launchers;
- forwards `changes` to the Python CLI with the right installed folder;
- documents the command in the help of `x86qw.sh` and `x86qw.cmd`;
- keeps `x86qw changes --sync-gitignore` for regenerating the filter by hand.

Release 0.7.10 stays historical and immutable. The public bootstrap now points
at the 0.7.11 bundle and at the next version of the TUF metadata.

## Validation

- a RED regression reproducing `x86qw: comando desconhecido: changes`;
- real runs of the installed launcher on Unix and Windows;
- the full suite, site and portable contracts.
