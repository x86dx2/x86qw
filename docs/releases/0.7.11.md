# x86QW 0.7.11

Hotfix do dispatcher da CLI permanente instalada.

## Correção

- aceita `x86qw changes` nos launchers Unix e Windows;
- encaminha `changes` para a CLI Python com o diretório instalado correto;
- documenta o comando na ajuda de `x86qw.sh` e `x86qw.cmd`;
- preserva `x86qw changes --sync-gitignore` para regeneração manual do filtro.

A release 0.7.10 permanece histórica e imutável. O bootstrap público passa a
apontar para o bundle 0.7.11 e para a versão seguinte da metadata TUF.

## Validação

- regressão RED reproduzindo `x86qw: comando desconhecido: changes`;
- execução real do launcher instalado em Unix e Windows;
- suíte completa, site e contratos portáveis.
