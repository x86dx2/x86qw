# x86QW 1.0.5

The source and the current installer move to `1.0.5`. `1.0.4` and the earlier
versions stay in the catalog as historical, not as current.

## What goes in

- the packaged installer uses only the canonical `qw.x86.com.br` domain for
  the catalog and the TUF metadata; the old domain is neither restored nor
  used as a fallback;
- a compact project banner shows before the download, with the name, the
  pitch, the canonical site and the installer version;
- a hybrid terminal flow: progress and results stay in sequence, while the
  interactive menus keep a controlled redraw;
- PowerShell failures keep the exit code and show a short message, without
  dumping the bootstrap script on the terminal.

## What does not change

- the `owner-only` audience; `external-public` stays `NO-GO`;
- earlier packages and tags stay immutable;
- the SHA-256, size, ZIP and TUF metadata validation stays fail-closed;
- Windows stays in preview until it gets equivalent native evidence.

## Validation

- automated regression tests of the banner on Unix and PowerShell;
- a regression test of the PowerShell error without `Write-Error` and without
  a `Line |` block;
- inspection of `manager.py` inside the package to require `qw.x86.com.br` and
  reject `x86qw.x86.com.br`;
- deterministic validation of the bundle and the public catalogs.
