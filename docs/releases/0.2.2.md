# x86QW 0.2.2

A corrective release of concurrency and of finishing installations in the
`0.2.x` line.

## Fixes

- a single lock per installation for stacks and every mutating operation;
- read compatibility with the format 1 locks of `0.2.1`;
- recovery blocked by a live or inconclusive journal controller;
- sensitive temporaries without hashes and without recursive removal;
- releasing the lock attempted independently of the other cleanup steps;
- shutdown of the whole POSIX group, and a Job Object on Windows;
- local permission repairs and macOS preparation available offline;
- tests for concurrency, a missing lock, a reused PID, descendants and faults
  injected while finishing.

## Compatibility

The public commands, profiles, stable/nightly, v1/v2 states, five games,
gameplay, personal settings and existing bundles stay compatible. `0.2.1`
stays immutable in the history.

## Validation

- full validation and Git LFS;
- maintenance and site tests;
- an Ubuntu, macOS and Windows matrix on Python 3.10 and a recent version;
- a Worker dry run;
- review of the immutable bundle and its hashes;
- a protected gate and a separate human approval to publish.
