# x86QW 0.2.2 — rascunho

**Estado:** não publicada, não marcada como `current` e não apontada pelo
bootstrap público.

Este arquivo é apenas o rascunho das notas de uma futura release corretiva. A
preparação do bundle imutável, a atualização atômica do catálogo e do bootstrap
e a publicação exigem PR e aprovação separados.

## Correções previstas

- lock único por instalação para stacks e todas as operações mutáveis;
- compatibilidade de leitura com locks de formato 1 da `0.2.1`;
- recuperação bloqueada por controlador de journal vivo ou inconclusivo;
- temporários sensíveis sem hash e sem remoção recursiva;
- liberação de lock tentada independentemente das demais etapas de limpeza;
- encerramento do grupo POSIX completo e Job Object no Windows;
- reparos locais de permissão e preparação macOS disponíveis offline;
- testes de concorrência, ausência de lock, PID reutilizado, descendentes e
  falhas injetadas na finalização.

## Compatibilidade

Os comandos públicos, perfis, stable/nightly, estados v1/v2, cinco jogos,
gameplay, configurações pessoais e bundles existentes permanecem compatíveis.
A `0.2.1` continua imutável e permanece a versão pública atual até uma etapa de
release explicitamente aprovada.

## Validação antes de publicar

- validação integral e Git LFS;
- testes de manutenção e site;
- matriz Ubuntu, macOS e Windows em Python 3.10 e versão recente;
- dry-run do Worker;
- revisão do bundle imutável e dos hashes;
- aprovação humana separada para publicar.
