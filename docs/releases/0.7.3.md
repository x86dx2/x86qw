# x86QW 0.7.3

A maintenance fix for macOS installations that update the upstream stable
client.

## macOS stable

- accepts upstream bundles without declared entitlements, such as the ezQuake
  stable 3.6.9 the distribution preserves;
- still treats stable as not sandboxed when `codesign` returns only a
  diagnostic and no entitlements plist;
- still rejects a truly invalid entitlements plist;
- does not change the signature, `Info.plist`, sandbox or contents of the
  stable bundle.

## Validation

- a specific regression test for a bundle without entitlements;
- maintenance suite: 1,198 tests passed, 37 explicit skips;
- a local smoke on the installed `ezQuake Stable.app` bundle confirmed
  `app_is_sandboxed=False`.

> Status: **published and verified**. `0.7.3` is the `current` version; `0.7.2`
> and every earlier version stay immutable in the history.
