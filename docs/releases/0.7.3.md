# x86QW 0.7.3

Correção de manutenção para instalações macOS que atualizam o cliente stable
upstream.

## macOS stable

- aceita bundles upstream sem entitlements declarados, como o ezQuake stable
  3.6.9 preservado pela distribuição;
- continua tratando o stable como não sandboxed quando `codesign` retorna
  somente diagnóstico e nenhum plist de entitlements;
- mantém a rejeição de plist de entitlements realmente inválido;
- não altera assinatura, `Info.plist`, sandbox ou conteúdo do bundle stable.

## Validação

- regressão específica para bundle sem entitlements;
- suíte de manutenção: 1.198 testes aprovados, 37 skips explícitos;
- smoke local no bundle instalado `ezQuake Stable.app` confirmou
  `app_is_sandboxed=False`.

> Estado: **publicada e verificada**. A `0.7.3` é a versão `current`; a `0.7.2`
> e todas as versões anteriores permanecem imutáveis no histórico.
