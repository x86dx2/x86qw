# x86QW 0.7.12

A hotfix of the transactional finish of `uninstall --purge`.

## Fix

- removes symlinks that belong to the quarantine without following their
  targets;
- correctly finishes the TUF cache that holds `metadata/root.json` as a link;
- uses an exclusive rename and inode identity on POSIX;
- uses a native handle opened on the reparse point on Windows;
- still keeps sockets, devices and other unauthorized special nodes.

In 0.7.11, the transaction could be committed and leave the finish incomplete
when it met the symlink the TUF cache itself creates. 0.7.12 removes that
incompatibility without widening the removal boundary.

Release 0.7.11 stays historical and immutable. The public bootstrap now points
at the 0.7.12 bundle and at the next version of the TUF metadata.

## Validation

- a RED regression reproducing the kept quarantine;
- a test that the link is removed and its external target stays intact;
- 1,418 maintenance tests and five site tests;
- the protected matrix on Ubuntu, macOS and Windows with Python 3.10 and 3.13.
