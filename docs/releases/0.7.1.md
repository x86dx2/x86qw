# x86QW 0.7.1

A corrective release of the bootstrap and the installed launchers.

> Status: published and verified. `0.7.1` is the `current` version; the
> `0.7.0` bundle and release stay immutable in the history.

Bundle: `x86qw-installer-0.7.1.zip` · 157113 bytes · SHA-256
`a0946ffcc8a4e1181dbc55ea08caf54691b18b12e901d12069eb2064b38c0d80`.

## Python

- requires Python 3.10 or newer before any download or change;
- uses the same deterministic order per platform in the bootstrap and the
  launcher;
- generates the launcher with the Python executable the installation actually
  used;
- looks for a compatible fallback if that runtime is removed;
- keeps paths with spaces/Unicode and unlimited arguments on Windows.

## PowerShell

- runs the bootstrap in its own scope, without opening another process or
  closing the session used by `irm ... | iex`;
- restores the caller's preferences and encodings, without leaking internal
  variables;
- keeps only the installer's code in `$LASTEXITCODE` as an intentional global
  effect;
- passed the native Windows PowerShell 5.1 evidence.

## Integrity

- computes the bundle's SHA-256 by streaming in the Unix bootstrap;
- adds a version guard to the zipapp before loading the manager;
- keeps the `0.7.0` bundle and release entirely intact.

## Validation done

- 393 maintenance tests and four site tests;
- 7/7 green jobs: Quality gate, Ubuntu, macOS and Windows with Python 3.10 and
  3.13;
- `git diff --check`, Git LFS, full validation and a Worker dry run;
- long arguments, paths with spaces/Unicode, exit codes, no leaks from the
  PowerShell session and early rejection of Python 3.9.

The portable checks are not the same as graphical or network smokes of the
runtimes. Those smokes stay pending where the roadmaps say so.
