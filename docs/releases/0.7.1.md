# x86QW 0.7.1

Release corretiva do bootstrap e dos launchers instalados.

> Estado: publicada e verificada. A `0.7.1` é a versão `current`; o bundle e a
> release `0.7.0` permanecem imutáveis no histórico.

Bundle: `x86qw-installer-0.7.1.zip` · 157113 bytes · SHA-256
`a0946ffcc8a4e1181dbc55ea08caf54691b18b12e901d12069eb2064b38c0d80`.

## Python

- exige Python 3.10 ou mais recente antes de qualquer download ou mutação;
- usa a mesma ordem determinística por plataforma em bootstrap e launcher;
- gera o launcher com o executável Python realmente usado na instalação;
- procura um fallback compatível caso esse runtime seja removido;
- mantém paths com espaços/Unicode e argumentos ilimitados no Windows.

## PowerShell

- executa o bootstrap em escopo próprio sem abrir outro processo ou encerrar a
  sessão usada por `irm ... | iex`;
- restaura preferências e codificações do chamador, sem vazar variáveis
  internas;
- preserva como efeito global intencional somente o código do instalador em
  `$LASTEXITCODE`;
- passou na evidência nativa do Windows PowerShell 5.1.

## Integridade

- calcula o SHA-256 do bundle em streaming no bootstrap Unix;
- adiciona guarda de versão ao zipapp antes de carregar o gerenciador;
- preserva integralmente o bundle e a release `0.7.0`.

## Validação concluída

- 393 testes de manutenção e quatro testes do site;
- 7/7 jobs verdes: Quality gate, Ubuntu, macOS e Windows com Python 3.10 e
