# x86QW 0.7.5

Hotfix do canal autenticado de atualização do x86QW.

## TUF

- incorpora ao instalador a root pública Ed25519 de produção;
- exige thresholds `2-de-3` para root e targets e `1-de-2` para snapshot e
  timestamp;
- autentica o catálogo pelo fluxo root → timestamp → snapshot → targets;
- publica consistent snapshots em `/api/v1/trust/`;
- falha de forma fechada quando a cadeia, o catálogo ou as versões divergem.

As dez chaves privadas não fazem parte do Git, do bundle, dos artefatos de CI
ou do site. A release 0.7.4 permanece histórica e imutável.

## Validação

- testes de threshold, expiração, rollback, equivocation e rotação de root;
- refresh real com `python-tuf` 7.0.0 sobre a metadata assinada;
- verificação do hash fixado da root incorporada;
- inspeção do ZIP para impedir material privado.
