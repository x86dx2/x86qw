# x86QW 0.7.5

A hotfix of x86QW's authenticated update channel.

## TUF

- embeds the production Ed25519 public root in the installer;
- requires `2-of-3` thresholds for root and targets and `1-of-2` for snapshot
  and timestamp;
- authenticates the catalog through the root → timestamp → snapshot → targets
  flow;
- publishes consistent snapshots under `/api/v1/trust/`;
- fails closed when the chain, the catalog or the versions disagree.

The ten private keys are not part of Git, the bundle, the CI artifacts or the
site. Release 0.7.4 stays historical and immutable.

## Validation

- tests for threshold, expiry, rollback, equivocation and root rotation;
- a real refresh with `python-tuf` 7.0.0 over the signed metadata;
- verification of the pinned hash of the embedded root;
- inspection of the ZIP to keep private material out.
