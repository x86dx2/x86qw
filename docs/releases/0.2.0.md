# x86QW 0.2.0

A consolidation release of the current platform, adding no new runtimes,
games, mods or maps.

## Highlights

- continuous CI on Ubuntu, macOS and Windows with Python 3.10 and 3.13;
- a manual, protected publishing gate, with full verification and Git LFS;
- safe, system-independent validation of PK3/ZIP members;
- passwords through a hidden prompt or a private file, with redaction;
- preflight, readiness, coordinated shutdown and session recovery;
- declarative catalogs of capabilities, runtimes, games and compatibility;
- `play` and `host` without installing a permanent payload;
- independent dependencies for MVDSV, QTV and QWFWD;
- docs, site, roadmaps and diagram in sync with the catalog.

## Migration

Installations with `.install/state.json` in format 1 are migrated one way to
format 2 during `install`, `update`, `upgrade` or `repair`. The custom
selection, the existing components, the historical fingerprints and the
personal files are kept. Format 1 stays accepted throughout this
compatibility line.

## Compatibility

The five current games, stable and nightly side by side, the shell and Windows
launchers and the existing public commands remain supported. MVDSV, QTV and
QWFWD stay available only on the platforms that have a declared artifact;
services are not offered for Intel macOS.
