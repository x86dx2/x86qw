# x86QW 0.2.0

Release de consolidação da plataforma atual, sem incorporar novos runtimes,
jogos, mods ou mapas.

## Destaques

- CI contínua em Ubuntu, macOS e Windows com Python 3.10 e 3.13;
- gate manual e protegido para publicação, com verificação integral e Git LFS;
- validação segura e independente do sistema para membros PK3/ZIP;
- senhas por prompt oculto ou arquivo privado, com redaction;
- preflight, readiness, encerramento coordenado e recuperação de sessões;
- catálogos declarativos de capacidades, runtimes, jogos e compatibilidade;
- `play` e `host` sem instalação de payload permanente;
- dependências independentes para MVDSV, QTV e QWFWD;
- documentação, site, roadmaps e diagrama sincronizados com o catálogo.

## Migração

Instalações com `.install/state.json` no formato 1 são migradas de forma
unilateral para o formato 2 durante `install`, `update`, `upgrade` ou `repair`.
A seleção customizada, os componentes existentes, os fingerprints históricos e
os arquivos pessoais são preservados. O formato 1 continua aceito durante esta
linha de compatibilidade.

## Compatibilidade

Permanecem suportados os cinco jogos atuais, stable e nightly lado a lado, os
launchers shell e Windows e os comandos públicos existentes. MVDSV, QTV e
QWFWD continuam disponíveis somente nas plataformas que possuem artefato
declarado; serviços não são anunciados para macOS Intel.
