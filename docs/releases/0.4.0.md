# x86QW 0.4.0

The release of the x86QW CLI's modern, task-oriented navigation.

## Navigation

- opens a main menu when `x86qw.sh` or `x86qw.cmd` runs without arguments;
- navigates with the arrow keys, `j`/`k`, Enter and Esc;
- searches games, modes, maps, versions, components and servers with `/`;
- keeps a numbered fallback where interactive navigation is unavailable;
- adds multi-select of components with Space.

## Gameplay and services

- shows options specific to Race, CTF and Frogbots only when they apply;
- guides the setup of MVDSV, QTV and QWFWD through contextual menus;
- keeps the safe password options and the existing preflights;
- handles cancelation without starting games or services.

## Compatibility

Every public command and flag stays available for automation and advanced use.
Games, gameplay, profiles, stable/nightly, PAKs and the installed layout did
not change.

## Validation

- 284 maintenance tests and four site tests;
- the Ubuntu, macOS and Windows matrix with Python 3.10 and 3.13;
- Git LFS, catalog, zipapp and a deterministic bundle;
- a TTY smoke of navigation, search and cancelation;
- a Worker dry run and explicit publishing after approval.
