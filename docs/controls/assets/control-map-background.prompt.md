# Fonte visual do mapa de controles

O arquivo `control-map-background.png` foi gerado para este projeto com a
ferramenta ImageGen integrada ao Codex. Ele é apenas a superfície visual; o
teclado, as cores e todo o conteúdo funcional são HTML/CSS verificável.

## Prompt

```text
Use case: infographic-diagram
Asset type: subtle background texture for an editable x86QW keyboard-controls poster
Primary request: Create an original dark industrial sci-fi arena surface, viewed perfectly top-down, suitable as a quiet background behind a keyboard control diagram.
Scene/backdrop: charcoal-black and graphite metal panels with restrained cyan-blue edge glow, faint worn stone/metal texture, very low visual noise, no central object.
Style/medium: polished game UI background, realistic material texture but restrained and flat enough for high-contrast vector labels.
Composition/framing: 16:9 landscape, open clear center and lower area for a keyboard diagram, gentle vignette, no perspective tilt.
Lighting/mood: low-key, competitive arena atmosphere, cyan accents only.
Color palette: #090d12, #111923, #182633, muted cyan #52c7d9.
Text: none.
Constraints: no keyboard, no logo, no characters, no weapons, no symbols, no watermark, no legible text, no bright hotspots, no gradients that reduce legibility.
```
